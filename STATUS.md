## Deviations
- plains-med (NAICS 561320/621399) returns only 10 notices in the 7-day window; kept 7 days for a consistent snapshot across firms; third profile stays on the plan's cut list.
- No `ptype` filter at query time so the tier counters run on the full stream (awards, special notices included).
- SAM emits `NONE` and `""` for unrestricted set-asides; both are treated as unrestricted in every firm's eligibility rule.
- Distance rule at state-centroid precision files a notice only beyond 2x the owner's limit (a state centroid can sit 200+ miles from the real site).
- No-submit URL guard inspects URL-valued tool inputs only, not free text, so a SOW that quotes a sam.gov link is not blocked. It is scoped to sam.gov hosts by design (reviewer HOOKS-05 noted `evil.com/submit-offer` passes; the guard protects the portal, tool-name stems cover the rest).
- Base-period rule (`rc-base`, 12-month minimum) has no live example in this week's snapshot: 11 notices state a base period and all are 12 months; two state 120 days / 25 weeks and are now parsed. The rule stays in the profile as an owner rule; the gallery will not claim it fired.
- Sole-source set-aside codes (`SDVOSBS`, `8AN`) removed from Sooner's and Plains Med's eligibility rules (reviewer DEF-09): a sole-source notice already names its awardee.
- Sooner's past-performance keywords widened to the vocabulary a cyber/IT firm's records carry (`security`, `cyber`, `SOC`, `SIEM`, `SOAR`, `incident response`, `information technology`, `IT services`, `IT support`): the whole-word rule had killed a SOAR RFI and an Army IT-services CSO at tier 0 on zero overlap.

- Past-performance rule (`ss-pp`) never files a notice whose description says the scope is in an attached SOW/PWS (fix-review NEW-13, option 2): the rule exists to save a model call, not to reject a notice the firm never read. Costs one Haiku call per such notice (1 this week).
- Web design direction chosen by the lead without owner input (`_runs/2026-09-13_phase4_web/SPEC.md`): dark blue-black desk read, amber signal, Bricolage Grotesque + IBM Plex, one animated tier-sieve bar as the signature element, two-column ledger-line layout. Public link = CloudFront + S3 static page and gallery JSON, Lambda Function URL proxy (SigV4) in front of the AgentCore Runtime; "Run live" degrades to the cached snapshot with a dated banner when SAM is throttled.
- Deny list uses specific verbs (`make_payment`, `transfer_funds`, `wire_transfer`) instead of bare `pay`/`transfer`, which blocked reading Service Contract Act pay rates (fix-review NEW-05). The bare `sign` stem stays; a future `read_sign_in_sheet` tool needs an explicit allow entry.
